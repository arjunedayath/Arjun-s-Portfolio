# Arjun Aju | Robotics & Technology Portfolio

Interactive portfolio website featuring real-time content management backed by Supabase.

## Features
- **Main Portfolio (`index.html`)**: Dynamic portfolio showcasing robotics projects, credentials, technical skill stack, and academic background. Real-time updates via Supabase.
- **Admin CMS Dashboard (`admin.html`)**: Secure, authenticated control panel to update projects, certifications, bio, and images with instant cloud synchronization.
- **Supabase Cloud Backend**: Serverless database and storage with Row Level Security (RLS) and Realtime change-data-capture broadcasts.

## Live Access
- **Portfolio**: `https://<your-username>.github.io/<repo-name>/`
- **Admin Dashboard**: `https://<your-username>.github.io/<repo-name>/admin.html`
